# 学院网络 IP 规划与设计材料
## 设计取舍
- 服务器区严格使用 `172.16.1.0/26`，服务器可用地址 `172.16.1.1-172.16.1.61`，网关 `172.16.1.62`。
- 个人计算机严格使用 `192.168.0.0/21`，按办公、教学、科研、研究生和 6 个学生实验 VLAN 划分。
- Packet Tracer 仿真采用代表性终端验证方案：每个业务 VLAN 放 2 台代表 PC，服务器区放 3 台代表服务器；报告中的地址规划覆盖全部 1900 台 PC 与 50 台服务器。
- 六台三层交换机组成环形三层骨干，互联口使用 /30 传输网段并运行 RIPv2；每台三层交换机负责本地 VLAN 的 SVI 默认网关。

## 路由设计
采用 RIPv2，所有三层交换机开启 `ip routing`，互联口配置为三层口，加入 `network 10.0.0.0`；承载业务 VLAN 的交换机再按需加入 `network 192.168.0.0` 或 `network 172.16.0.0`。关闭自动汇总 `no auto-summary`，避免 192.168.0.0/21 被错误按类汇总。

## Packet Tracer 文件生成方式
在已启动 PT-MCP Builder 桥接后运行：

```bash
pt-reverse/bin/pt730-topo apply --replace pt-reverse/course-design/college-network-topology.json
pt-reverse/bin/pt730-topo query
```

## 网站功能版块初步设计
| 版块 | 功能描述 |
|---|---|
| 学院首页 | 展示学院新闻、通知公告、快速入口和重要链接。 |
| 学院概况 | 介绍学院历史、机构设置、师资队伍、实验中心和联系方式。 |
| 教学管理 | 发布培养方案、课程安排、实验预约、考试安排、教学资源下载。 |
| 科研平台 | 展示科研方向、科研团队、项目成果、论文专利和合作平台。 |
| 研究生教育 | 提供招生信息、导师介绍、课题方向、学术活动和培养流程。 |
| 学生实验平台 | 提供实验室开放时间、实验环境说明、预约入口、安全规范和常见问题。 |
| 服务器服务门户 | 集中入口到 DNS/WWW/数据库/文件服务，提供运行状态和维护公告。 |
| 网络运维公告 | 发布网络维护、故障通告、IP/VLAN 申请流程、软件下载和帮助文档。 |

## 课程报告可引用的配置文件
